Por que Codis?

Python puro. Zero Electron.

A maioria dos editores modernos usa Electron (Node.js + Chromium). O Codis prova que Python + Tkinter é suficiente para construir uma experiência completa, fluida e visualmente expressiva.

❌ Electron (VSCode, Cursor, etc.)
# Dependências típicas
Node.js + npm
Chromium embedded (~150MB)
Electron runtime
~200–500 MB download
RAM idle: 300–800 MB
# Cada processo filho = novo Chromium
✅ Codis (Python + Tkinter)
# Dependências obrigatórias
Python 3.12+ (já instalado)
Tkinter (incluso no Python)
~5 MB download (source)
RAM idle: ~60 MB
# Um único processo Python
# Tudo mais é opcional, sob demanda
